# Запуск для жюри

Нужен **Node.js 20.20+**. Для оценивания: **Ollama 0.40.15+**, работающий локально, и установленная **qwen3.5:9b**. Сборки и обязательного `npm install` нет. Интернет нужен для первоначальной установки инструментов и весов; оценивание выполняется локально.

Из папки проекта:

```powershell
node scripts/doctor.mjs
npm start
```

Откройте **http://127.0.0.1:3000**. Проверка ничего не устанавливает, не скачивает, не оценивает и не изменяет `.env` или результаты. Она обращается только к метаданным локального Ollama, не выводит URL датасета и тексты диалогов. `FAIL` означает, что готовность текстового оценивания не подтверждена (код выхода 1); `WARN` относится к необязательному аудио. Даже без модели можно открыть интерфейс и импортировать JSON. Проверка не измеряет качество модели, свободную видеопамять или доступность адреса DEV.

## Если модель ещё не установлена

Запустите установленное приложение Ollama. Если служба не запущена, выполните `ollama serve` в отдельном терминале. Затем:

```powershell
ollama pull qwen3.5:9b
node scripts/doctor.mjs
```

Загрузка весов занимает несколько гигабайт. Эти команды нужны только при подготовке компьютера. Для переносимой установки Windows см. `scripts/setup-local.ps1` и `scripts/start-local.ps1` в README: второй скрипт может скачивать модель. Обычная проверка `doctor` загрузок не делает.

## Откуда взять диалоги

Чистая копия не содержит частные DEV/PROD, сохранённые оценки или очередь команды. После запуска сервера можно импортировать небольшой публичный набор:

```powershell
node scripts/examples.mjs import
```

Три разговора ABCD появятся в отдельной группе **EXTERNAL-ABCD**. Выберите её в интерфейсе и запустите оценивание. Источники, лицензии и контрольные суммы находятся в `samples/manifest.json`. Это примеры для проверки работы, **не официальный Ground Truth**. Они не должны попадать в DEV/PROD и сдаваемые результаты.

Для своего JSON-файла нажмите «Загрузить диалог» слева внизу главного экрана. Настройки модели и история доступны по прямому адресу `http://127.0.0.1:3000/classic`, загрузка аудио — `http://127.0.0.1:3000/audio`. Для DEV создайте конфигурацию, только если её ещё нет:

```powershell
if (!(Test-Path -LiteralPath '.env')) { Copy-Item -LiteralPath '.env.example' -Destination '.env' }
```

В `.env` укажите `DATASET_URL` из кнопки GET в Student Guide и перезапустите приложение. Для ручного JSON-импорта `.env` не нужен. Не публикуйте этот файл и подписанный URL. Модель, выбранная ранее в интерфейсе, хранится в `.local/state.json`: изменение `OLLAMA_MODEL` не заменяет сохранённый выбор; меняйте его в `/classic`.

## Необязательная проверка аудио

Нужен **Python 3.10+**. Укажите один и тот же интерпретатор при установке и в `CQA_PYTHON` файла `.env`:

```powershell
./scripts/setup-audio.ps1 -Python 'C:/path/to/python.exe'
# В .env: CQA_PYTHON=C:/path/to/python.exe
node scripts/doctor.mjs
```

Установка скачивает зависимости в `.local/audio-python` и модели в `.local/audio-models`; эти папки не входят в Git. После перезапуска сервера загрузите запись на `/audio` или выполните `node scripts/examples.mjs audio` для двух записей Perit. Дождитесь распознавания, прослушайте фрагменты, проверьте текст и назначьте роли голосов. Только после подтверждения черновика запускайте оценивание. На CPU обработка может занять несколько минут.

## Если запуск не удался

- **Ollama недоступен:** проверьте, запущен ли он, и `OLLAMA_URL=http://127.0.0.1:11434`. Разрешён только локальный HTTP. Если проверка выполняется в ограниченной среде, ей нужен доступ к loopback.
- **Модель отсутствует или облачная:** установите локальные веса и выберите их в `/classic`; выполните проверку повторно.
- **Ошибка памяти модели:** попробуйте установленную `qwen3.5:4b` через `/classic`. Её качество необходимо проверять отдельно.
- **Порт 3000 занят:** если это уже CQA, откройте существующий сервер. Для другого приложения задайте свободный `PORT` в `.env`. Не останавливайте чужой процесс автоматически.
- **Не работает аудио:** проверьте `CQA_PYTHON`, повторите установку с тем же Python и запустите `doctor`. Наличие файлов не гарантирует успешного распознавания конкретной записи.

Данные сохраняются в `.local/state.json`, аудио — в `.local/audio`. Остановить свой сервер: `Ctrl+C`. Не запускайте два экземпляра с общим состоянием и не удаляйте состояние ради повторной демонстрации: в нём находятся результаты и очередь.
