# CQA Implementation Plan

> For agentic workers: use subagent-driven-development or executing-plans; execute the user-approved plan without a second approval gate.

**Goal:** working local CQA prototype with real dataset and local inference.
**Architecture:** Node built-in HTTP server, modular scoring/validation/model/storage, vanilla accessible frontend. Ollama native JSON-schema inference; local JSON persistence with atomic writes.
**Tech Stack:** Node >=20, HTML/CSS/ES modules, Node test runner, Ollama.
**Spec:** docs/spec.md

## Global Constraints
- Only local inference; no synthetic model outputs presented as real.
- Exact rubric and NA rules in spec; 85.38 manual example must pass.
- Secrets and dataset excluded from git; API bound to loopback by default.
- Preserve original evaluation and historical rubric across appeals and edits.

## Review Focus
- Malformed model output and invalid evidence must fail visibly.
- Batch failure must preserve prior completed items.
- Changed rubric must trigger fresh evaluation and not mutate past results.
- Interrupted dialog is not automatically NA for every criterion.
- Imports must be safe rendered text and validate all data before mutation.

Interfaces: defaultRubric(); validateRubric(input); normalizeConversations(input); validateAnswers(rubric,conversation,answers); calculateScore(rubric,answers); Store(file). State includes rubrics, conversations, evaluations, appeals, jobs, settings.
