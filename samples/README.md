# Открытые примеры для проверки CQA

Это **внешние тестовые разговоры**, не DEV/PROD и не официальный Ground Truth. Предварительно выставленных оценок здесь нет. Файлы доступны сразу после клонирования репозитория; большие корпуса и облачные сервисы не нужны.

```powershell
npm run examples -- list
npm run examples -- import
npm run examples -- audio
```

Приложение должно быть запущено для import/audio. `list` проверяет SHA-256 локальных файлов. `import` добавляет три чата в `EXTERNAL-ABCD`; `audio` загружает два звонка в обычный аудиопроцесс и выводит ссылки для ручной проверки. Повтор audio использует имеющуюся запись с тем же хешем, если она не завершилась ошибкой. Для повторной независимой проверки можно загрузить файл вручную.

`npm run examples -- evaluate` импортирует чаты и ставит настоящую оценку всех трёх в очередь по официальному чек-листу. Он не меняет выбранный пользователем чек-лист и не включает примеры в конкурсную выгрузку.

## Perit AI — два полных ролевых звонка

Источник: [Perit Duplex Support Conversations (English)](https://huggingface.co/datasets/perit-ai/perit-duplex-support-en), автор Perit AI, лицензия [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

- `perit/bluetooth.flac`: 167.064 с, фактически смена пароля Wi-Fi. В метаданных источника: Bluetooth Wont Connect, исполнители Aldo и Michael.
- `perit/malware.flac`: 167.160 с, фактически подготовка к установке интернета. В метаданных источника: Malware Popup, исполнители Michael и Aldo.

В исходнике 48 kHz, два канала, по одному человеку на канал. Сохранены обе дорожки и весь разговор. Единственное изменение: WAV перекодирован в FLAC **без потерь**; совпадение декодированного PCM проверено. Это постановочные сценарии поддержки с живыми исполнителями, не реальные обращения клиентов. `examples audio` выбирает режим раздельных каналов. Какой голос является оператором, нужно подтвердить по содержанию; нельзя считать speaker_0 оператором автоматически.

Обнаруженные несоответствия метаданных источника: файл с названием Bluetooth фактически содержит обращение о смене пароля Wi-Fi, а Malware — о подготовке к установке домашнего интернета. Мы сохраняем названия и метаданные источника для воспроизводимости, а систему проверяем по содержанию записи, не по её имени.

## ASAPP Research — три чата ABCD

Источник: [Action-Based Conversations Dataset](https://github.com/asappresearch/abcd), официальный файл `data/abcd_sample.json`, автор ASAPP Research (2021). Лицензия MIT скопирована в `abcd/LICENSE`.

- `abcd-3592`: возврат неподходящего размера и передача менеджеру.
- `abcd-9489`: статус возврата денег.
- `abcd-3695`: срок действия промокода.

`abcd/source-sample.json` сохраняет опубликованный пример; `abcd/conversations.json` — формат нашего импорта. Все исходные сообщения сохранены в порядке публикации, включая системные действия. agent/customer/action переименованы в operator/client/system; к ID добавлен префикс abcd-. Исходник не содержит времени сообщений: метки `Turn ... (source has no timestamps)` обозначают порядок и не имитируют скорость ответа. Персональные данные сценариев вымышлены согласно описанию ABCD. Сценарные ответы и внутренние правила ABCD не передаются модели как скрытые подсказки.

## Воспроизводимость и пределы проверки

`manifest.json` содержит закреплённые версии источников, прямые ссылки, SHA-256 скачанных и используемых файлов, сведения о преобразованиях. Баллы по Freedom для внешних разговоров — применение нашего чек-листа к другому домену. Без правил соответствующей службы нельзя независимо проверить все утверждения оператора. Проверяйте реальные цитаты, обоснованность N/A, роли, отсутствие выдуманных фактов и сохранение первоначальной оценки после апелляции.
